# ChurchStats v0.11

2026/02/11

出欠登録改修計画 Phase 6 および Phase 6 デバッグ・機能修正を実装したバージョン。

## 本バージョンでの追加・変更内容

### Phase 6: 合同集会の扱い方針（2026/02/11 修正）

合同集会トグルは **meetings テーブルにのみ影響** し、出欠記録は **地区別（地区集会）に統一** する方針に変更した。

- **合同集会トグル**: 記録モード時のみ表示。`sunday_meeting_modes` でトグルON時は meetings に地方集会レコード（`district_id=null`, `locality_id=X`）を作成するが、出欠記録には使わない。
- **出欠記録**: 常に地区集会（`district_id=X`）に紐づく。合同集会ON時も、各メンバーの `district_id` に応じて地区集会の meeting に保存する。
- **`mergeDistrictAttendanceToLocality`** を削除。地区集会の出欠を地方集会へ統合する処理は行わない。

### Phase 6: 在籍期間の複数期間対応

同じメンバーが時期を跨いて複数回所属する可能性に対応し、在籍期間を複数登録できるようにした。

#### スキーマ（マイグレーション 021）

- **`member_local_enrollment_periods`** テーブルを新規作成。
  - `member_id`, `period_no`, `join_date`, `leave_date`, `is_uncertain`
  - 既存の `members.local_member_join_date` / `local_member_leave_date` を期間1として移行。
  - RLS を設定（SELECT: authenticated、INSERT/UPDATE/DELETE: reporter 以上）。

#### 名簿編集

- **「ローカル在籍期間を追加する」** ボタンを追加。クリックで新規期間を追加できる。
- 各期間に「ローカルメンバー転入日」「ローカルメンバー転出日」「期間不確定」トグルを表示。
- 期間1の転入・転出日は `members` にも同期（後方互換）。

#### 在籍判定

- `enrollmentPeriod.ts` の `isInEnrollmentPeriod` を拡張。`enrollment_periods` が存在する場合はいずれかの期間に該当すれば在籍と判定。従来の `local_member_join_date` / `local_member_leave_date` も引き続きサポート。

#### 名簿管理アコーディオン

- 名簿一覧の展開行に **ローカルメンバー転入日** を表示。複数期間の場合は「期間1: YYYY-MM-DD」「期間2: YYYY-MM-DD」のように表示。
- **ローカルメンバー転出日** は値がある場合のみ表示、NULL なら非表示。

#### デバッグ「在籍期間不確定リスト」

- **`/debug/enrollment-uncertain`** ページを新規追加（管理者専用）。
- **グループ A**: 期間1の転入日が NULL のメンバー。
- **グループ B**: いずれかの期間で `is_uncertain = true` のメンバー。
- 各行に編集リンクを表示。

### Phase 6: 単一地区読込ロジックの統一

- 単一地区・非合同モード時も `ensureSundayMeetingsBatch` で集会を取得するように変更。「全地区」と同様の経路に統一し、出欠登録画面で「まだ記録はありません。」となる問題を解消。

### Phase 6 デバッグ・機能修正

#### 閲覧モード出欠列の表記

- **欠席の表示**を「ー」から「×」に変更（主日・祈りの集会・小組集会）。
- オンライン・他地方の NULL を示す「ー」と区別するため。

#### 列タイトルの表記変更・人数表示

- **オンライン** のラベルを「オンライン」から「ｵﾝﾗｲﾝ」に変更（主日・祈りの集会）。
- 出欠・ｵﾝﾗｲﾝ・他地方の列タイトルに人数を表示。例: `出欠(12)`、`ｵﾝﾗｲﾝ(3)`、`他地方(1)`。
- 括弧は半角 `()` を使用。

#### 祈りの集会で「他地方で出席」を非表示

- [祈りの集会] において、他地方で出席は該当しないため、**閲覧モード・記録モードの両方**で「他地方で出席」列を非表示にした。

#### 小組集会のグルーピング初期値

- [小組集会] の表示設定で、**グルーピング1層目のデフォルトを「地区」** に変更した。

## トラブルシューティング

### 1. ダッシュボードでは主日人数は正しいが、出欠登録では「まだ記録はありません。」と表示される

#### 現象
- ダッシュボードの週別主日出席グラフでは、該当週の主日出席者数が正しく表示される。
- 一方、出欠登録画面（主日集会タブ）で同じ日付・同じ地区（例：稲城地区）を選択すると、「まだ記録はありません。」と表示され、出欠一覧が空になる。

#### 原因
- 単一地区表示時は `district_id` で直接クエリしていたのに対し、「全地区」表示時は `ensureSundayMeetingsBatch` を使用していた。取得ロジックの差異により、集会が見つからない場合があった。

#### 対処結果
- 単一地区・非合同モード時も `ensureSundayMeetingsBatch` で集会を取得するように統一。これにより「全地区」と同様の経路で集会を取得するようになり、出欠が正しく表示される。
