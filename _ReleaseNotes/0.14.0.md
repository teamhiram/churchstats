## 本バージョンでの追加・変更内容

### 週別主日出席グラフの出席者カウント修正

- v0.13 の欠席コメント保存修正により、全メンバーに `attended: false` レコードが作成されるようになった副作用で、グラフが出席・欠席の全員をカウントしていた問題を修正。
- `StatisticsCharts.tsx` の `weeklyData` 計算で `attended !== false` フィルタを追加し、出席者のみをカウントするように修正。

### 「横並び」トグルの追加

- 週別主日出席グラフに「横並び」トグルを新設（デフォルト OFF）。
- ON にすると、信仰別・年代別・地区別の各系列が積み上げ（スタック）ではなく横並び（グループ）で表示される。
- 横並び時は各バーの上にそれぞれの値を個別表示。
- 「集計のみ」モードではトグルは非表示。

### 枠組設定（地区・小組）のUI改善

- **ラベル変更**: 「リネーム」を「編集」に変更（地区の設定・小組の設定の両方）。
- **小組の削除**: 一覧の削除ボタンを廃止し、編集モーダル内に「この小組を削除」を赤文字テキストで配置。クリックで削除確認UI（名前入力・削除ボタン）が下に展開する形に変更。
- **コンテナの簡素化**: 地区・小組の各ブロックの角丸・ボーダー・シャドウを廃止し、余白のみのシンプルな表示に。
- **地區セクションタイトル（小組の設定）**: 背景を廃止し、文字色を緑に変更。
- **アコーディオン高さ**: 地区と小組のアコーディオン行の高さを小組側に統一（`py-2` で統一）。

### 枠組設定・メンバーリスト編集の改善

- **リスト表示順**: 地区・小組のメンバーリスト（レギュラー／準レギュラー／プール）をフリガナ順で表示するように変更（未設定時は名前でソート）。
- **準レギュラー操作**: 準レギュラーリストの移動ボタンを上下矢印から左右矢印に変更（← レギュラーへ / → プールへ）。
- **変更件数バッジ**: メンバーリスト編集モーダルのタイトル横に、変更があった件数をオレンジのバッジで表示。
- **2列レイアウト**: メンバーリスト編集で、1行に2名表示。名前が長い場合は1行で省略表示し、ホバーで全文を表示。
- **モーダル高さとスクロール**: メンバーリストモーダルの高さを、PCでは画面の70％（`max-h-[70vh]`）、スマホでは動的ビューポートの90％（`90dvh`）に制限。リストが多い場合はリスト部分のみ縦スクロールし、スクロールバーを常時表示。

### 出欠登録の表示リスト

- **デフォルト表示**: 主日集会・祈りの集会・小組集会の各タブで、表示リストをデフォルトで「レギュラー」のみに変更。
- **表示設定トグル**: 表示設定アコーディオン内に「準レギュラー」「プール」のトグルを追加（デフォルト OFF）。ON にすると該当リストの名前が表示リストに追加される。OFF の場合でも、出欠・オンライン・他地方・メモのいずれかに入力があれば、その名前行は出欠記録対象として表示リストに残る。
- **行の見た目**: メモ欄の上下 padding を削減して行の高さを低く。準レギュラーの名前行は薄い黄色背景、プールの名前行は薄い青背景で表示。
- **セクションアコーディオン時のテーブルタイトル**: グルーピング（地区順・小組順・出欠別など）でセクション表示にしている場合、各アコーディオンを開くと、その直下に列見出し（名前・出欠・ｵﾝﾗｲﾝ・他地方・メモ）の行を表示。1層目・2層目の各セクションごとにテーブルタイトルが付く。

### 出欠登録でゲストの名前をグレー表示

- 主日集会・祈りの集会・小組の集会の出欠登録で、ゲスト（選択中の地区・小組に属さず、他地方・他グループから出席した人）の名前を薄いグレーで表示。
- 閲覧モード・記録モードの両方で適用。検索から追加したゲストも同様にグレー表示。

### 週別主日出席グラフの凡例

- **集計のみでも凡例表示**: 「集計のみ」選択時も凡例を表示するように変更。凡例のラベルは地方名（未設定時は「全体」）。
- **12週平均の表示**: 凡例に過去12週間の平均値を表示。表示形式は半角かっこと数値のみの「(5.2)」形式（「12週平均」の文言はなし）。
- 信仰別・年代別・地区別モードでは、各系列ごとに凡例ボタンと平均値が表示され、クリックで系列の表示／非表示を切り替え可能。

### 記録を削除する

- 「記録モードに切り替える」ボタンの左に「記録を削除する」ボタンを追加（主日集会・祈りの集会・小組集会の各タブ）。
- クリックで確認ポップアップ（「本当に記録を削除しますか？削除した出欠データは復元できません。」）を表示し、キャンセル／削除するを選択。削除するで当該集会の出欠記録を一括削除。

### デバッグログのクリーンアップ

- `StatisticsCharts.tsx`、`dashboard/page.tsx`、`sunday/page.tsx` から以前の調査用 `fetch` ログ（`#region agent log`）を削除。

### 名簿・ダッシュボードの名前リンクを閲覧ページに統一

- **名簿一覧（メンバーリスト）**: 名前をクリックしたときのリンク先を編集ページ（`/members/[id]/edit`）から閲覧ページ（`/members/[id]`）に変更。フィルター（type=guest 等）はクエリで維持。
- **ダッシュボードの出欠マトリクス**: 名前のリンク先を同様に閲覧ページに変更。
- 閲覧ページの「編集」ボタンから従来どおり編集画面へ遷移可能。
