# ChurchStats v0.19

2026/02/26

デバッグまわりを強化。集会重複検知の一括選択・各種数値の登録集会数セクション・サイドバーへの該当件数バッジを追加し、在籍期間不確定のラベルを短縮した。あわせてモバイルUIを調整（アカウントボタンをフッターへ、設定サブメニューのコンパクト化・フッターを隠さない、他画面の左右余白追加）。


## 本バージョンでの追加・変更内容

### 集会重複検知

- **出席者0を一括選択**: 重複グループ一覧の上に「出席者0を一括選択」ボタンを追加。押下で出席者数が 0 の集会のみ選択され、そのまま一括削除できる。
- **選択列の全選択**: 「選択」列ヘッダーをテキストからチェックボックス＋「選択」ラベルに変更。そのチェックでグループ内の行を一括選択／解除。セクション右上の「このグループを選択」は削除し、表ヘッダーで統一。

### 各種数値

- **登録集会数セクション**: 既存カードの下に「登録集会数」セクションを追加。主日集会（`lordsday_meeting_records` の `meeting_type='main'` 件数）、小組集会（`group_meeting_records` 件数）、派遣件数（`organic_dispatch_records` 件数）を表示。
- **ラベル変更**: 「出欠レコード数」を「主日集会延べ人数」に変更（延べ件数であることが分かりやすく）。

### デバッグサイドバーの該当件数バッジ

- **集会重複検知**: 重複グループ数を赤バッジで表示。`getMeetingDuplicateGroupCount()` で件数を取得し、layout 経由でサイドバーに渡す。
- **重複出席**: 当年の同一週・同一メンバーで2件以上の主日出欠グループ数を赤バッジで表示。`getDuplicateAttendanceGroupCount()` で取得。
- **在籍期間不確定**: ラベルを「在籍期間不確定リスト」から「在籍期間不確定」に短縮。該当メンバー数（グループA∪Bのユニーク人数）を赤バッジで表示。`getEnrollmentUncertainCount()` を `debug/enrollment-uncertain/actions.ts` に追加し、layout で取得してサイドバーに渡す。

### 設定ページのスクロール

- **挙動**: 設定／デバッグ画面ではスクロール時にサイドバーは動かず、右側のメインコンテナのみスクロールするようにした。
- **対応**: main を `overflow-hidden`＋`flex flex-col min-h-0` にし、MainContentWrapper を `flex-1 flex-col min-h-0 overflow-hidden` に。SettingsShell で、サイドバー表示時は右カラムにのみ `overflow-auto` を付け、サイドバー非表示時は children を `flex-1 min-h-0 overflow-auto` の div でラップしてコンテンツ側だけスクロール。

### モバイルUIの調整

- **アカウント（人型）ボタン**: スマホではヘッダー右上から削除し、フッターの「設定」の右隣に配置。PC は従来どおりヘッダー右端のまま。
- **設定サブメニュー（スマホ）**: 設定画面ではスマホ時にサイドバーを一切出さず、サブメニューはフッター「設定」タップで開くモーダルのみで表示。モーダル内のリストをスマホ向けにコンパクト化（ul/li、項目 min-h-44px、ヘッダー・角丸の縮小、max-h 60vh）。
- **設定モーダルとフッター**: モーダルにフッター高さ分の下マージン（`mb-[calc(1.875rem+env(safe-area-inset-bottom))]`）を付け、フッターが隠れないようにした。
- **左右の余白**: 設定以外の画面（ダッシュボード・週別・出欠・名簿）のメインコンテンツに `px-4 md:px-6` を追加。設定ページは従来どおり（変更なし）。
- **スマホで地方選択**: 複数地方がある場合、モバイルヘッダー右に現在の地方名＋▼ボタンを表示。タップで地方選択ポップアップを開く。ポップアップは PC 用から切り出し、モバイル・PC で共通表示するようにした。
