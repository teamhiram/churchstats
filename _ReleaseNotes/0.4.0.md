# ChurchStats v0.4

2026/02/05
commit and push.

0.3 に引き続き開発。ナビ・レイアウトのモバイル対応と出欠登録画面のUI改修を実施。その後、モバイルナビの挙動・スタイルと名簿管理の表示を調整。さらに、出欠登録の「すべての地区」選択時の表示（祈りの集会・有機的派遣・小組集会）と小組ドロップダウンの表記・挙動を統一した。

## 本バージョンでの追加・変更内容

### モバイル対応（ナビゲーション）

- **モバイル時:** サイドバーを非表示とし、画面右下に丸いハンバーガーボタン（FAB）を固定表示。タップで右からスライドするドロワーを開き、ナビリンク・アカウント（氏名・ロール・所属地方・ログアウト）を一括表示。
- **PC時:** 従来のサイドバーを廃止し、画面上部に**トップ固定ナビゲーション**を配置。ナビリンクは横並び。「氏名・ロール・所属地方・ログアウト」は右端の**「アカウント」**メニュー（ドロップダウン）にまとめた。
- **レイアウト:** ダッシュボードのメインコンテンツは、PC 時のみトップナビの高さ分の余白（`pt-12`）を付与。

### グローバルナビのスタイル・高さ

- **アクティブメニュー:** 現在のページに対応するリンクを、バー高さいっぱいの矩形・白文字・濃い緑背景（`bg-primary-700 text-white`）で表示。非アクティブはグレー文字・ホバーで薄い背景。
- **ナビの高さ:** PC のトップナビを細くし、`h-14` → `h-12`（48px）に変更。メインの上余白も `pt-14` → `pt-12` に合わせた。
- **アクティブ判定:** 「出欠登録」は `/meetings` のほか `/meetings/sunday`・`/meetings/prayer` など出欠タブ配下でもアクティブに。週別集計（`/meetings/list`）のときは「出欠登録」ではなく「週別集計」がアクティブ。「システム設定」は **`/settings` のみ**アクティブ。「枠組設定」は `/settings/organization` のときのみアクティブ（枠組設定ページでシステム設定が同時にハイライトされないよう修正）。

### モバイルナビ・ドロワーの配色統一（PCグロナビに合わせる）

- **ドロワー内ナビリンク:** アクティブを `text-primary-600 bg-primary-50` から **`bg-primary-700 text-white`** に変更（PC のアクティブタブと同じスタイル）。非アクティブは `text-slate-600 hover:bg-slate-100` で PC と統一。

### モバイルナビ・ドロワーの挙動・スタイル更新

- **ドロワー（モーダル）の位置:** ハンバーガーボタンを隠さず、ボタンの**上**にパネルが開く。画面下端まで伸ばさず、必要分の高さのみ（`max-h` で制限）。角を `rounded-xl` でカード風に。
- **開閉:** ハンバーガーボタンのタップで開閉をトグル。閉じる専用ボタンと「メニュー」の見出しは削除。オーバーレイタップでも閉じる。
- **ハンバーガーボタン（FAB）のスタイル:** 半透明・リキッドグラス風に変更。`bg-primary-500/20`・`backdrop-blur-md`・`border-white/30`。ホバー時は `bg-primary-500/35`。アイコンは `text-primary-700` で視認性を確保。
- **モーダルアニメーション:** スライドインなどのアニメーションを削除し、即時表示に変更。

### バックアップの配置変更

- **グロナビ:** 「バックアップ」リンクを削除。
- **システム設定内:** バックアップ・リストアの**中身**（エクスポート・インポート）をシステム設定ページ（`/settings`）に直接配置。別ページへのリンクやリダイレクトは行わない。
- **旧ルート:** `/backup` および `/settings/backup` の専用ページは削除。

### 集会画面のメインコンテンツ表示修正

- **現象:** 出欠登録の集会画面で、フィルター・タブの下のメインコンテンツが隠れて見えにくい。
- **原因:** 集会レイアウトのフィルター・タブ用ラッパーに負の上マージン（`-mt-4 md:-mt-6`）が指定されており、固定グロナビの直下に重なっていた。
- **対応:** 上方向の負のマージンを削除（`-mx-4 md:-mx-6` のみ残し、横方向のフル幅表示は維持）。フィルター・タブがグロナビの下から正しく並び、メインコンテンツも隠れないようにした。

### ダッシュボードの数字集計をコンパクトに

- 地方・地区・小組・メンバー登録数・集会登録数のカードについて、パディング（`p-4` → `px-3 py-2.5`）、ラベル（`text-sm` → `text-xs`）、数値（`text-2xl` → `text-lg`）、グリッド間隔（`gap-4` → `gap-2 sm:gap-3`）を縮小。モバイルで 2 列・sm で 3 列にし、数値に `tabular-nums` を付与。

### 名簿管理のモバイル対応

- **モバイル時:** フィルター・並び順・グルーピングの各コントロールを画面上に並べず、**アイコンボタン**で開く**モーダル**に集約。フィルター用（じょうごアイコン）・並び順用（ソートアイコン）・グルーピング用（レイヤーアイコン）の 3 つ。適用中はボタンを primary 色でハイライト。
- **PC時:** 従来どおりフィルター・並び順・グルーピングを画面上に表示。
- **リストのセル:** 改行を防ぐためセルの padding を縮小（`px-2 py-1.5` → `px-1.5 py-1`）。フリガナ・地区・小組・年齢層・聖徒/友人のセルに `whitespace-nowrap` を付与。
- **スマホ時のフリガナ:** 一覧の「フリガナ」列は非表示（`hidden md:table-cell`）。フリガナは行をタップして開く**アコーディオン（展開行）**内に表示。PC では従来どおりテーブル列で表示。

### 出欠登録画面のUI改修

- **主日集会**
  - 「名簿（出欠・メモ）」という見出しを削除。
  - フリー検索（名前）・並び順・グルーピング 1 層目を、**アコーディオン**（「フリー検索・並び順・グルーピング」）にまとめ。開閉で表示・非表示を切り替え。
- **祈りの集会**
  - 「名簿（出欠・オンライン・他地方・メモ）」という見出しを削除。
- **小組集会**
  - 「名簿（出欠・メモ）」という見出しを削除。
- **有機的派遣**
  - 「名簿（派遣記録・そのまま編集）」という見出しを削除。
  - 小組用ドロップダウンにラベル「小組」を表示。先頭オプションを**「すべての小組」**に変更。「すべての小組」選択時は、その地区の全小組のメンバーを一覧表示し、派遣記録の表示・編集が可能。保存時はメンバー所属小組の `group_id` を使用。地区変更時の初期値は「すべての小組」。
  - **「すべての地区」選択時:** 地区が「全ての地区」のときもリストが空にならないよう、小組を地区で絞らず全小組を取得してメンバー一覧を表示するように修正。

### 出欠登録：「すべての地区」選択時の表示・小組表記の統一

- **祈りの集会**
  - **「すべての地区」選択時:** リストが空だった不具合を修正。日曜礼拝と同様に、地区が「全ての地区」のときは全地区のメンバー・出欠を集約して一覧表示するように変更。実施日選択は単一地区時のみ表示。「全ての地区」時は出欠の登録・変更は不可（表示のみ）とし、説明文「全ての地区を表示しています。出欠の登録・変更は地区を選択してから行ってください。」を表示。

- **有機的派遣**
  - 小組ドロップダウンの表記を**「すべて」→「すべての小組」**に変更。ラベル「小組」を追加し、表示結果がラベルと対応するようにした。

- **小組集会**
  - **デフォルトを「すべての地区」に:** 報告者以上で小組集会を開いたとき、URL に `district_id=__all__` を付与してリダイレクトし、フィルターの地区が「全ての地区」で表示されるようにした。
  - **小組ドロップダウン「すべての小組」:** 地区が「すべての地区」のときは小組を地区で絞らず全小組を取得。小組の初期値を「すべての小組」にし、ドロップダウンに「すべての小組」オプションを追加。「すべての小組」選択時は全小組のメンバー・その週の小組集会出欠を集約表示。実施日選択は非表示。出欠・メモは編集不可（表示のみ）。説明文「すべての小組を表示しています。出欠の登録・変更は小組を選択してから行ってください。」を表示。

### 有機的派遣の保存条件と集計の見直し

- **保存・削除ルール**
  - **種類・日付・メモの3項目をすべて入力したときのみ** DB（`organic_dispatch_records`）に保存。いずれかが空の場合は保存しない。
  - 一度入力した後にいずれかの項目を空にすると、該当レコードを `organic_dispatch_records` から**削除**する（派遣先としてカウントされない）。
- **ページ離脱時の警告**
  - 種類・日付・メモのいずれかだけ入力した「未完了の行」がある状態で、タブを閉じる・更新・別サイトへ移動しようとすると、ブラウザの離脱確認で「種類・日付・メモの3項目をすべて入力しないと保存されません。」と表示。
  - 画面上にも「種類・日付・メモの3項目をすべて入力すると保存されます。3項目入力しないままページを移動すると保存されません。」という注意書きを表示。
- **週別集計の派遣先カウント**
  - 週別一覧・週別詳細では、**種類・日付・メモの3項目がすべて入力されているレコードのみ**を「派遣先」としてカウント・表示。不完全なレコード（古い仕様で一部だけ保存されたもの含む）は集計に含めない。
