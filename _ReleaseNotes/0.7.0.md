# ChurchStats v0.7

2026/02/08
local test only.

0.6 以降の出欠仕様の見直しと、出欠登録ナビの改善を実施する。あわせて、0.6 で実装済みだったが ReleaseNote_0.6 に記載が漏れていた項目を補足する。

## 本バージョンでの追加・変更内容

### （補足）0.6 で実装済みだったが ReleaseNote_0.6 に記載が漏れていた項目

- **【出欠登録/主日集会】スマホ向けメモ UI**
  - スマホではメモ欄を表示せず、テーブル見出しから「メモ」ラベルを非表示にした。メモ欄の代わりに SVG のメモアイコン（グレー）を表示。タップでポップアップが開き、入力して確定する。
  - メモがある場合は、独立した行として下部に小さいフォントで表示し、メモアイコンはブルーで表示する。
  - オンライン・他地方の出席列は左右の padding を最小限（`px-1`）にし、スペースを確保した。

- **【出欠登録/有機的派遣】派遣メモをメモアイコンに**
  - 派遣メモ欄を主日集会と同じメモアイコン＋ポップアップ方式に変更。スマホではアイコンタップでポップアップ入力・確定。

- **ちらつき防止のためリローディングを削除**
  - 出欠登録（主日・祈りの集会・小組集会）のトグル・メモ保存時には `router.refresh()` を呼ばず、クライアントの状態更新のみで表示を変えるようにした。画面のちらつきを抑えるため。

- **【スマホのメニュー】フッター固定メニューへ変更**
  - ハンバーガーボタンを廃止し、**フッター固定メニュー**（速報・週別・出欠・名簿・設定）に変更。タップ回数を減らし、主要画面へ 1 タップで遷移できるようにした。設定はタップでサブメニュー（枠組設定・システム設定・アカウント詳細）を展開。

### 出欠の仕様変更（トグル純粋・メモは記録のみ）

主日集会・祈りの集会・小組集会の出欠登録について、**出欠はトグルのみで判定し、メモは記録するが集計には使わない**仕様に変更した。

- **変更前（0.6）の挙動**
  - 出欠トグルをオフにしたとき、メモがあればレコードを残し「欠席・メモあり」、メモがなければレコードを削除していた。
  - メモだけ入力して保存すると、レコードが新規作成され「欠席・メモあり」として保存されていた。

- **変更後（0.7）の挙動**
  - **出欠は出欠トグルのみで判定する。** 集計（週別出席数・欠席アラート・週別集計など）はすべて `attended` の値のみを使用し、メモの有無は集計に影響しない。
  - **トグルをオフにしたときはレコードを削除せず、`attended = false` に更新する。** メモの有無にかかわらず、常に更新のみ行う。
  - **メモは「既にレコードがあるとき」だけ保存できる。** レコードがない状態でメモだけ入力して保存しても、新規レコードは作成されない。出欠トグルでレコードを作成したうえで、メモを追記・編集する。

- **データベース**
  - マイグレーション **014_attendance_attended_flag.sql** の内容を更新。既存行で `attended` が NULL の場合は `attended = true` に更新する `UPDATE` 文を追加した。既に 014 を適用済みの環境では、この `UPDATE` のみを SQL Editor 等で実行すればよい。

### 出欠登録ナビに「先週」「翌週」を追加

主日・祈りの集会・小組集会・有機的派遣の出欠登録画面で、週選択のドロップダウンの**左に「先週」、右に「翌週」**ボタンを追加した。

- クリックで 1 週間前・1 週間後の週に移動する。
- 年をまたぐ場合（例：1 月第 1 週の「先週」で前年 12 月になる場合）は、URL の `year` と `week_start` の両方が更新される。

## データベース

- **014 を未適用の場合:** `014_attendance_attended_flag.sql` をそのまま適用する（ALTER + UPDATE が含まれる）。
- **014 を既に適用済みの場合:** 既存行の `attended` が NULL のときのみ出席扱いにするため、次の SQL を実行する。

```sql
UPDATE attendance_records SET attended = true WHERE attended IS NULL;
UPDATE prayer_meeting_attendance SET attended = true WHERE attended IS NULL;
UPDATE group_meeting_attendance SET attended = true WHERE attended IS NULL;
```
