# v0.25.0 リリースノート

JGWの年代に合わせるためのDBマイグレーションStep1
フロントへの影響は限定的。

## 年代（年齢層）の拡張と統一

### 新規年代の追加
- **青年・中年・壮年・年長**を年代選択肢に追加（マイグレーション 042）。DB の `category_enum` に `young` / `middle` / `late_middle` / `senior` を追加し、アプリではラベルを「青年」「中年」「壮年」「年長」で表示。
- **大人（社会人）**は過渡期のため残し、ラベルを **「社会人(年代不詳)」** に変更。既存の `adult` データはそのまま利用でき、後から青年・中年・壮年・年長へ振り分け可能。

### 中学生・高校生の統合
- **中学生・高校生を「中高生」に統一**（マイグレーション 044）。DB の `category_enum` から `high_school` を削除し、`junior_high` のみを使用。既存の `high_school` データはすべて `junior_high` に変換済み。
- 名簿追加・編集・一覧・出欠・統計の各所で、選択肢および表示ラベルを「中高生」に統一。

### 年代の表示順の統一
- 年代の表示順を **未就学 → 小学生 → 中高生 → 青年 → 中年 → 壮年 → 年長 → 大学生 → 社会人(年代不詳)** に統一。
- ダッシュボード統計グラフの凡例・メンバー登録画面の年齢層ボタン・名簿一覧のソート・年代フィルター・出欠画面のグルーピングで、共通の `CATEGORY_ORDER` を参照するように変更。

---

## グループ（小組）に地方を追加

- **groups テーブルに `locality_id` を追加**（マイグレーション 043）。地区（district）経由でなく、小組から直接所属地方を参照可能に。既存データは `district_id` から `locality_id` を一括投入済み。
- 地方ラベル（市川・調布など）は `localities` を JOIN して `name` を取得。小組一覧・選択肢で地方名を表示する場合はこの JOIN を利用。
