2026/02/08
local test only.

0.5 に引き続き開発。バグ潰しと UI の最適化を実施する。

## 本バージョンでの追加・変更内容

### 出欠登録：フリー検索・並び順・グルーピングの統一

主日集会で提供している「フリー検索・並び順・グルーピング」機能を、祈りの集会・有機的派遣・小組集会の出欠登録画面にも実装した。

- **祈りの集会（`/meetings/prayer`）**
  - 主日集会と同じ「フリー検索（名前）」「並び順」「グルーピング1層目」を追加。
  - 並び順：フリガナ順・地区順・小組順・年齢層順。
  - グルーピング：地区・小組・年齢層・信者。
  - **デフォルトはフリガナ順。**

- **有機的派遣（`/meetings/organic`）**
  - 主日集会と同じ「フリー検索（名前）」「並び順」「グルーピング1層目」を追加。
  - 並び順：フリガナ順・地区順・小組順・年齢層順。
  - グルーピング：地区・小組・年齢層・信者。
  - **デフォルトはフリガナ順。**
  - フリー検索で他小組のメンバーを名簿に追加し、種類・日付・メモを入力して保存できる。

- **小組集会（`/meetings/small-group`）**
  - 主日集会と同様の「フリー検索（名前）」「並び順」「グルーピング1層目」を追加。
  - 並び順は**地区順を除く**：フリガナ順・小組順・年齢層順（小組単位のため地区順は非表示）。
  - グルーピング：地区・小組・年齢層・信者。
  - **デフォルトはフリガナ順。**

いずれの画面も、名簿の上にある「フリー検索・並び順・グルーピング」のアコーディオンを開くと、検索・並び替え・グルーピングのオプションを変更できる。

### 出欠トグルがオフでもメモを保存

主日集会・祈りの集会・小組集会の出欠登録で、**出欠トグルがオフでもメモに入力があればそのレコードを保存する**ように変更した。

- **挙動**
  - 出欠トグルをオフにしたとき、メモ欄に文字が入っていればレコードは削除せず「欠席だがメモあり」として更新して残す。
  - メモが空のままトグルをオフにしたときは従来どおりレコードを削除する。
  - トグルがオフの状態でメモだけ入力して保存（blur）すると、レコードが新規作成され「欠席・メモあり」として保存される。
  - トグルがオフのレコードを再度オンにすると、出席として更新される。

- **データベース**
  - マイグレーション **014_attendance_attended_flag.sql** で、`attendance_records`・`prayer_meeting_attendance`・`group_meeting_attendance` に `attended` カラム（BOOLEAN, DEFAULT true）を追加。既存行は `attended = true` として扱われる。
