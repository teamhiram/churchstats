## 氏名・フリガナの分割（姓・名）

- **members テーブルに氏名・フリガナの分割列を追加**（マイグレーション 045）。`last_name`（姓）・`first_name`（名）・`last_furigana`（姓ふりがな）・`first_furigana`（名ふりがな）を追加。既存の `name` / `furigana` から一括投入するバッチ用マイグレーション 046 も用意。
- **`Member` 型**（`src/types/database.ts`）に上記カラムを反映。名簿追加・編集・一覧・出欠・統計などで、表示は `formatMemberName` / `formatMemberFurigana` で統一。
- **名簿一覧のフリガナ表示**を `last_furigana` + 半角スペース + `first_furigana` に統一（片方だけの場合は存在する方のみ表示）。
- **members.name の NOT NULL を解除**（マイグレーション 049）。氏名は `last_name` / `first_name` を正とし、`name` は今後必須にしない方針に変更。

---

## 年代（age_group）の値変更

- **`junior_high`（中高生）を `adolescent`（青春期）に変更**（マイグレーション 047）。DB の `category_enum` を `RENAME VALUE` し、既存レコードおよび `attribute_histories` の履歴値を `adolescent` に更新。表示ラベルは従来どおり「中高生」。

---

## 名簿メモ（members.memo）

- **members テーブルに `memo` 列を追加**（マイグレーション 048）。長文・段落OKの名簿用メモを保存可能に。
- **名簿追加画面**でメモ入力欄を追加。登録時に `memo` を保存。
- **名簿詳細画面**のプロフィールに「メモ」を表示。改行・段落は `whitespace-pre-wrap` で保持。

## 設定UI改善（ローカル設定 / バックアップ・リストア / 権限まわり）

- **「ローカル管理」表記を「ローカル設定」に変更**（設定UI全体の見出し・案内文など）。
- **設定 → ローカル設定 → 氏名不完全** を追加。
  - 現在選択中の地方の名簿から、`last_name` / `first_name` / `last_furigana` / `first_furigana` のいずれかが空欄のメンバーを一覧表示
  - 鉛筆アイコンからポップアップで4項目をまとめて編集可能
  - サイドバーで該当件数を赤バッジ表示
- **サイドバーの「ローカル設定」配下を整理**。
  - `枠組設定` と `表示設定（旧: システム設定）` をローカル設定配下へ移動
  - **氏名不完全**は **表示設定の後ろ**へ移動し、該当件数を **赤バッジ**で表示
- **バックアップ・リストアを独立ページ化**（`/settings/backup`）。
  - 旧「表示設定（旧: システム設定）」内のセクションから移動し、**データベース整理**配下に配置
- **アカウントモーダルに「疑似ロール切替」を追加**（システム管理者のみ）。
  - グローバルロール / ローカルロールをドロップダウンで選択し、**表示・機能の制限を疑似的に確認**できる
  - **モーダル自体は制限を受けず**、いつでも疑似ロールを変更できる
- **設定 → ローカル設定 → ユーザ・ロール管理（地方）**（`/settings/local-admin/users`）を追加（ローカル管理者以上。システム管理者も可）。
  - 対象地方をページ上で明示（地方切替で対象地方も切替）
  - ユーザ一覧（その地方に関係するユーザー）を表示（`user_localities` / `local_roles` / `profiles.locality_id` を統合）
  - メアドで招待し、対象地方へのアクセス＋ローカル権限を付与（サービスロールキー設定時）
  - スマホでも見やすいレスポンシブ表示（カード表示）
  - ゴミ箱アイコンで「その地方からユーザーを削除」（`user_localities` / `local_roles` から除外）
- **ローカル設定メニューの見え方改善**。
  - ローカル管理者（local_admin）の場合、Cookie/プロフィールの地方が未設定のときは **管理者の地方をデフォルト選択**するよう調整

## メンバーステータス（members.status）

- **members に `status` を追加**（マイグレーション 050）。
  - `active`（正常） / `left`（転出） / `rest`（逝去） / `inactive`（非表示） / `tobedeleted`（削除予定）
  - 既存レコードは全て `active` に設定
- **名簿編集**でステータス選択を追加。
  - ボタン式で「正常・転出・逝去」
  - 画面下部に「非表示にする」「削除する」のリンクを追加（注意文つき）
- **ローカル設定**に一覧ページを追加。
  - `非表示リスト`（`/settings/local-admin/inactive`）… 出欠登録画面から隠れる（統計は反映）
  - `削除予定`（`/settings/local-admin/to-be-deleted`）… 統計・集計から除外
  - いずれもサイドバーで該当件数を赤バッジ表示
- **名簿ページ**（`/members`）では `tobedeleted` を表示しない
- **出欠登録画面**では `inactive` / `tobedeleted` をメンバー検索・選択から除外
- **統計・集計**では `tobedeleted` のみ除外（`inactive` は含める）

## 設定メニュー再編（データベース整理）

- **デバッグ配下を「データベース整理」に統合**。
  - `全テーブル` / `集会一覧` / `集会重複検知` / `バックアップ・リストア` を「データベース整理」へ集約
  - 「デバッグ」セクションは廃止し、残りの項目（各種数値・在籍期間不確定・重複出席）も「データベース整理」に統合
  - **グローバル管理**セクションは **データベース整理の前**に表示

## 設定サイドバー改善（ローカル管理者 / メニュー順）

- **「ローカル管理者」セクションを追加**し、**ユーザ・ロール管理（地方）**（`/settings/local-admin/users`）を **その配下へ移動**。
