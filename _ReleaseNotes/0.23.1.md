## LINEアナウンス文

統計システム0.23.1
2026/03/01
祈りの集会の閲覧モードにおいて、「全ての地区」の表示の不具合の修正しました。

## 修正内容

### 出欠／祈りの集会
- **「全ての地区」の動作**: 祈りの集会で「全ての地区」を選んでも稲城地区の記録のみ表示されていた不具合を修正しました。
- **原因**: (1) URL の `district_id=__all__` が現在地方の default にフォールバックしていた (2) 表示用の地区リストが現在地方（例: 稲城）のみだったため、「全ての地区」選択時も稲城の地区 ID だけでクエリしていた。
- **対応**: `getMeetingsLayoutData` で地方フィルタ前の全地区リスト（`allDistricts`）を返すようにし、集会レイアウトの地区ドロップダウンには全地方の地区を表示。祈りの集会ページでは「全ての地区」選択時に `allowAllDistricts` を有効化し、コンポーネントに全地区リストを渡すようにしました。これにより調布＋稲城など全地方の祈りの集会記録がまとめて表示されます。

## 確認・テスト観点

- 出欠／祈りの集会で地区を「全ての地区」にしたとき、調布・稲城など全地方の記録が一覧に含まれること。
- 特定の地区を選んだときは従来どおりその地区のみ表示されること。
- 主日・小組・有機的伝道の出欠ページは従来どおり動作すること。
