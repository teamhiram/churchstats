## デプロイ警告の解消

- `start-server-and-test` を `devDependencies` から削除。
  - このパッケージの v3 系は Node `^22 || >=24` を要求するため、Node 20 環境（Vercel）で `EBADENGINE` 警告が発生していた。
  - プロジェクト内の npm scripts では未使用だったため、削除して警告を解消。
- `package-lock.json` を同期更新。
