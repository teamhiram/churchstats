## 本バージョンでの追加・変更内容

### 出欠マトリクスをダッシュボードに追加

ダッシュボード（週別主日出席グラフの下）に**出欠マトリクス**セクションを追加した。

- **表示内容**: 祈り・主日・小組・派遣の4行で、各週の出席（■）／欠席（□）をスクエアで表示する。
- **色分け**: 各項目ごとに色をペアで設定。トグルとスクエアが同色になる。
  - 祈り: 緑
  - 主日: 青
  - 小組: 黄
  - 派遣: 紫
  - 欠席: グレー
- **レイアウト**: 名前列は固定、週列は横スクロール可能。各列の上に週番号（1, 2, 3...）を表示する。
- **表示制御**: 祈り・主日・小組・派遣の各行をトグルで表示・非表示に切り替えられる。スクエアサイズは −／＋ ボタンで調整可能（8px〜24px）。
- **対象メンバー**: 表示期間内にいずれか1つでも出席があるメンバーのみ表示する。
- **並び順**: フリガナ順（デフォルト）／名前順。
- **グルーピング**: 地区別（デフォルト、地区ID順で調布→稲城）／なし。
- **年選択**: 現在年・前年・2年前を選択して表示可能。

### トグルコンポーネントに checkedClassName を追加

共通トグルコンポーネント（`components/Toggle.tsx`）に、ON時の背景色を指定できるオプション `checkedClassName` を追加した。出欠マトリクスの各行トグルで、項目ごとに色を分けるために使用している。

### 週別集計の地方ドロップダウンを管理者のみに制限

週別集計（`/meetings/list`）の**地方**フィルターを**管理者（admin）のみ**表示するように変更した。共同管理者以下には表示されず、アカウントのデフォルト地方で集計される。管理者向けに表示する場合は、アンバー系の枠・背景と「管理者」ラベルでスタイルを区別している。API でも管理者以外の `locality` パラメータは無視される。

### デバッグメニューを管理者のみに制限

デバッグメニュー（全テーブル・重複出席・主日出席者デバッグ）を**管理者（admin）のみ**表示するように変更した。共同管理者（co_admin）・レポーター・閲覧者にはナビに表示されない。URL を直接入力してアクセスした場合でも、管理者以外はダッシュボードまたは週別集計へリダイレクトされる。管理者向けに、グローバルナビのデバッグボタン・ドロップダウンにアンバー系の枠・背景を適用し、週別集計の地方フィルターと同様のスタイルで管理者機能であることを区別している。

### ダッシュボードの棒グラフに地区別の色分けを追加

週別主日出席グラフの棒グラフの色分けオプションに**地区別**を追加した。各週の出席者を主日集会の地区ごとに積み上げて表示し、ツールチップで各地区の人数と出席者名を確認できる。

### ダッシュボードの棒グラフに各棒の合計を表示

週別主日出席グラフの各棒の上に、その週の出席者合計数を表示するようにした。集計のみ・信仰別・年代別・地区別のいずれの色分けでも合計が表示される。

### トグルコンポーネントの統一と knob 位置の修正

トグルスイッチを共通コンポーネント `components/Toggle.tsx` に統一した。knob（丸）が右に寄りすぎていた問題を修正し、左右 2px の余白を確保するよう位置を調整した。週別集計・表示設定・ member 作成・編集・主日・祈り・小組の出欠登録など、すべてのトグルでこのコンポーネントを使用する。

### グラフの「ゲストを含む」トグルに変更

ダッシュボードの週別主日出席グラフにおいて、「ローカルのみ」チェックボックスを「**ゲストを含む**」トグルに変更した。デフォルトは**OFF**（ローカルのみ表示）。ON にするとゲスト（非ローカル）も含めて集計される。

### ダッシュボードの「地方」表示を変更

地方の**数**ではなく、アカウントに紐づけられた**地方名**を表示するように変更した。`profiles.main_district_id` → `districts` → `localities` の関連から取得した所属地方名を表示する。地方が未設定の場合は「—」を表示する。週別主日出席グラフのカード右上にも地方名を表示するようにした。

### 棒グラフの色分けボタンをセグメントコントロール風に変更

週別主日出席グラフの「棒グラフの色分け」ボタン（集計のみ・信仰別・年代別・地区別）を、CodePen の switch-field 風セグメントコントロールに変更した。未選択はグレー背景＋内側シャドウ、選択中はプライマリカラーでフラット表示。

### トグルにトラックの内側シャドウとノブの立体感を追加

共通トグルコンポーネントのトラックに `shadow-inner` を追加し、ノブに `box-shadow` で立体感を付与した。

### 派遣モニターにコピーボタンを追加

派遣モニターの右下に「コピー」ボタンを追加した。クリックでタイトル・説明・主日欠席者・小組欠席者の内容をテキストでコピーできる。コピー完了後は「コピーしました」と 2 秒間表示する。

### サイトの primary カラーを Tailwind 規定の green に統一

Tailwind の規定色 `tailwindcss/colors` の `green` を primary として使用するように変更した。グローバルナビのアクティブ表示色を「グラフをPNGでダウンロード」ボタンと同じ緑（`primary-600`）に統一した。

### グローバルナビのデバッグメニューに右ボーダーを追加

デバッグメニュー（PC・モバイル共通）に、左に加えて**右側**にもオレンジの縦ボーダーを追加し、デバッグ領域を視覚的に区切った。

### 週別集計から出欠登録へ遷移時のエラーを修正

**現象**

週別集計（`/meetings/list`）の「← 出欠登録」ボタンを押して `/meetings/sunday?year=2026` へ遷移すると、以下のエラーが表示されていた。ブラウザをリフレッシュすると正常に表示される。

- エラーメッセージ: `Minified React error #310`（[React Error #310](https://react.dev/errors/310)）
- 内容: 「Rendered more hooks than during the previous render」（前回のレンダーより多くのフックがレンダーされた）

**原因**

`MeetingsFilterBar` コンポーネントで、条件付き `return null` の**後**に `useCallback` フックが配置されていた。これにより、週別集計ページでは 5 つのフック、出欠登録ページでは 7 つのフックが呼ばれ、ページ遷移時に React のフックルール違反が発生していた。

**対応**

すべてのフック（`goPrevWeek` と `goNextWeek` の `useCallback`）を、条件付き `return` の**前**に移動した。フックの呼び出し順序と数を常に一定にすることで、クライアントナビゲーション時にもエラーが発生しないようにした。
