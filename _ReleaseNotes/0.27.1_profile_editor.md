# ChurchStats v0.27.1

Push date: 2026-04-07
Purpose: 名簿プロフィール編集画面の改善と、削除予定リストの削除権限改善
---

## 名簿管理（プロフィール編集）

- **名簿編集画面に「メモ」欄を追加**。
  - 名簿追加画面で保存していた `members.memo` を、編集画面でも表示・更新できるようにした。
  - 長文入力に対応した `textarea` を使用し、既存メモがある場合は初期表示時に内容をセットする。
- **保存処理を更新**。
  - プロフィール編集の保存時に `members.memo` もあわせて更新されるようにした。
  - 「非表示にする」「削除する」などのステータス変更時も、同じフォーム内容としてメモを保持したまま保存できる。
- **在籍期間メモとの区別を明確化**。
  - 画面上に「在籍期間のメモとは別に保存されます」と補足を表示。
  - ローカル在籍期間ごとのメモ（`member_local_enrollment_periods.memo`）とは別物であることを明示。

---

## ローカル設定 > 削除予定

- **ローカル管理者でも、削除予定リストから物理削除できるように変更**。
- **個別レコードの削除リンク**を表示。
- **複数選択による一括削除**を追加。
- 削除権限は、**global admin / admin / co_admin / current locality の local_admin** に付与。
- 削除時は、対象が現在の地方かつ `tobedeleted` のメンバーに限定して処理する。

---

## 影響範囲

- 対象は **名簿プロフィール編集画面** と **設定 > ローカル設定 > 削除予定**。
- 既存の `members.memo` データ構造や名簿詳細画面の表示仕様には変更なし。
- 削除予定からの物理削除では、関連する出席・在籍データも外部キー設定に従って同時に削除される。
- `members` テーブルに対する DELETE 権限は、対象地方で effective admin の場合に許可するポリシーを追加。
