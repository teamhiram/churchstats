# ChurchStats v0.8

2026/02/09
local test only.

## 本バージョンでの追加・変更内容

### 祈りの集会：全ての地区での出欠登録

祈りの集会の出欠登録画面で「全ての地区」を選択した場合でも、出欠の登録・変更ができるようにした。各メンバーの所属地区の集会として出欠・オンライン・他地方で出席・メモを登録・編集できる。

### 出欠登録フィルターバーの幅調整

主日・祈りの集会・小組集会・有機的派遣の出欠登録画面で表示するフィルターバー（年・週・地区）のレイアウトを調整した。

- **地区ドロップダウン**の幅を約半分（1fr → 0.5fr）に縮小した。
- **期間**（年＋週選択）側に余った幅を再配分し、週ドロップダウンを広く使えるようにした（1.2fr → 1.7fr）。
